# COOKED? V1

COOKED? V1 is a focused daily student companion with:

- Attendance
- Opportunities
- Daily History
- Daily Law
- Personalized Daily News
- Suggestions / feedback
- About / support

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## API slots

All API placeholders are in `/home/runner/work/Cooked_/Cooked_/src/api`:

- `attendanceApi.js`
- `newsApi.js`
- `historyApi.js`
- `lawApi.js`
- `opportunitiesApi.js`
- `feedbackApi.js`
- `supportApi.js`

Each file contains `PASTE_API_ENDPOINT_HERE` for quick wiring.
