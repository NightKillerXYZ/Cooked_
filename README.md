# COOKED? V1

COOKED? V1 is a focused daily student companion with:

- Attendance
- Opportunities
- Daily History
- Daily Law
- Personalized Daily News
- Suggestions / feedback
- About / support

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

- `historyApi.js`
- `lawApi.js`

- `supportApi.js`
